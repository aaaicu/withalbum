WithAlbum Server

내 컴퓨터에서 직접 운영하는 사진 서버 · 관리 화면
개발 중 · 실험용
로그인·앨범 권한·백업이 동작합니다. 같은 집 LAN 공개는 TLS(자체 서명 인증서 + 지문 확인)일 때만 가능하며, 인터넷에 공개하거나 중요한 사진의 유일한 보관 장소로 사용하지 마세요. 이 관리 화면은 서버 컴퓨터에서(localhost) 여는 것을 권장합니다.

받은 초대 (Invitations)

나에게 온 앨범 초대입니다. 수락하면 해당 역할로 앨범에 참여합니다.

    앨범 (Albums)

    내가 소유하거나 초대된 앨범만 보입니다. 소유자(OWNER)인 앨범에서는 멤버·초대·소유권 이전·보관을 관리할 수 있습니다.

    파일 업로드 테스트

    비밀번호 변경

    변경하면 이 브라우저를 제외한 모든 기기가 로그아웃됩니다.

    내 기기 (Devices)

    로그인된 기기 목록입니다. 잃어버린 기기는 해지하세요. 현재 브라우저를 해지하면 로그아웃됩니다.

    저장소 상태 (Storage)

      원본 전체 검사는 서버 콘솔에서 withalbum-server verify (해시 포함: verify -hash)로 실행합니다. 이 화면은 서버 시작 시 점검 결과만 보여 줍니다.

      기기 연결 (TLS 지문)

      앱에서 서버를 추가할 때 아래 연결 정보(QR 내용)를 사용합니다. 지문이 서버 콘솔의 withalbum-server tls 출력과 같은지 꼭 확인하세요.

        인터넷 공개 및 실제 서비스 용도가 아닌, 서버 기능과 배포 방식 검증을 위한 단계입니다.
