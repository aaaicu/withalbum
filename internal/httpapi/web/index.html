WithAlbum 관리

내 컴퓨터에서 직접 운영하는 사진 서버입니다. 서버 콘솔에서 만든 계정으로 로그인하세요 (withalbum-server admin init / admin create-user).

개발 중 · 실험용로그인·앨범 권한·백업이 동작합니다. 같은 집 LAN 공개는 TLS(자체 서명 인증서 + 지문 확인)일 때만 가능하며, 인터넷에 공개하거나 중요한 사진의 유일한 보관 장소로 사용하지 마세요. 이 관리 화면은 서버 컴퓨터에서(localhost) 여는 것을 권장합니다.

저장장치 상태

자세히

    업로드는 서버가 받은 바이트의 SHA-256을 기록하고, 쓰기 직전마다 디스크 표식을 다시 확인합니다. 원본 전체 해시 검사는 서버 콘솔의 verify -hash로 실행합니다.

    받은 초대

    나에게 온 앨범 초대입니다. 수락하면 해당 역할로 앨범에 참여합니다.

      백업 · 서버 콘솔에서 실행이 화면은 백업 여부를 알 수 없어요. 다른 디스크로 withalbum-server backup -to를 정기적으로 실행하세요.
      접속 범위확인 중
      개인 앨범은 보이지 않아요관리자도 초대받지 않은 앨범의 사진은 볼 수 없어요.

      내 앨범

      내가 소유하거나 초대된 앨범만 보여요. 소유자(OWNER)인 앨범에서는 멤버·초대·소유권 이전·보관을 관리할 수 있어요.

      새 앨범

      앨범을 만들 권한이 없어요참여 중인 앨범은 그대로 쓸 수 있어요. 새 앨범이 필요하면 서버 관리자에게 앨범 생성 권한을 요청하세요.

      앨범

      파일 보내기 테스트

      브라우저가 먼저 SHA-256을 계산해 함께 보내고, 서버가 받은 바이트와 같을 때만 "원본 보관됨"으로 표시해요.

      기기 · 내 계정

      로그인된 기기와 비밀번호를 관리해요.

      내 기기

      잃어버린 기기는 해지하세요. 현재 브라우저를 해지하면 로그아웃됩니다.

      기기플랫폼마지막 사용동작

      비밀번호 변경

      변경하면 이 브라우저를 제외한 모든 기기가 로그아웃됩니다.

      저장장치

      원본이 저장되는 디스크의 연결과 쓰기 상태

      점검 결과

        다시 시작하려면

        1. 1외장 디스크를 서버 컴퓨터에 다시 연결하세요.
        2. 2Finder 사이드바(또는 mount)에 디스크가 보이는지 확인하세요.
        3. 3재검사로 상태를 확인하세요. 다시 연결하면 장치 번호가 바뀌어 계속 "연결 안 됨"일 수 있어요. 그때는 서버를 다시 시작하세요.
        가족 기기의 앱은 "서버 저장 중단"(503 storage_unavailable) 응답을 받아요. 서버가 원본을 확인하기 전에는 기기에서 사진을 지우지 않아요.

        원본 검사

        이 화면은 서버 시작 시 점검 결과와 지금의 연결 상태만 보여 줍니다. 원본 전체 검사는 서버 콘솔에서 실행하세요.

        • withalbum-server verify빠른 검사: 모든 원본의 존재·크기 확인, 아무것도 바꾸지 않음
        • withalbum-server verify -hash전수 검사: 모든 원본의 SHA-256 재계산

        사용자

        계정을 발급하고 서버 역할을 관리해요. 관리자도 다른 사람의 앨범 내용은 볼 수 없어요.

        새 사용자 만들기

        초기 비밀번호는 직접 전달하세요. 계정만으로는 어떤 앨범도 보이지 않고, 앨범 소유자가 초대해야 참여할 수 있어요.

        사용자 목록

        아이디이름역할앨범 생성상태동작

        백업·복구

        백업과 복원은 서버 콘솔 명령으로 실행해요. 이 화면에서는 실행하거나 상태를 확인할 수 없어요.

        원본이 디스크 하나에만 있으면 위험해요디스크가 고장 나면 되돌릴 수 없어요. 다른 디스크에 정기적으로 백업하세요. 자동 백업 일정은 아직 없어요.

        백업

        서버가 실행 중이어도 백업할 수 있어요. DB 스냅샷과 원본 증분 복사, SHA-256 매니페스트를 만듭니다.

        • withalbum-server backup -init -to <백업 디스크 폴더>처음 한 번: 백업 대상 폴더 등록
        • withalbum-server backup -to <백업 디스크 폴더>이후 매번: 바뀐 원본만 복사

        복원

        서버를 먼저 중지하세요. 복원하면 모든 기기가 로그아웃되고, 백업 이후에 올린 사진은 기기에서 다시 보내야 해요. 기존 데이터는 지우지 않고 옆에 보존합니다.

        • withalbum-server restore -from <스냅샷> -check검증만, 아무것도 바꾸지 않음
        • withalbum-server restore -from <스냅샷>전수 검증 후 원자적으로 교체

        서버 설정

        기기 연결과 접속 범위

        기기 연결 (TLS 지문)

        앱에서 서버를 추가할 때 아래 연결 정보(QR 내용)를 사용합니다. 지문이 서버 콘솔의 withalbum-server tls 출력과 같은지 꼭 확인하세요.

          접속 범위

          기본은 이 컴퓨터(127.0.0.1)에서만 열려요. 같은 집 LAN 기기는 -tls -allow-lan으로 시작하고 로그인 가능한 서버 관리자가 있을 때만 연결할 수 있어요. 인터넷 공개는 지원하지 않아요.
