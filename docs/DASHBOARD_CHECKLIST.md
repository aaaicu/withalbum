# 관리 웹 UI 수동 점검 체크리스트 (M17)

자동 테스트(`internal/httpapi/admin_test.go` 등)는 페이지 제공·CSP·CSRF·API 권한만 확인합니다. 실제 브라우저에서 화면이 동작하는지는 아래 순서로 사람이 확인합니다. 결과(브라우저·버전·날짜·통과/실패 항목)는 별도로 기록하세요.

## 준비

- [ ] 빈 테스트용 저장소 디렉터리를 만들고 `withalbum-server -init-storage` → `admin init`으로 관리자 계정 생성 (실제 사진 저장소를 쓰지 말 것)
- [ ] 콘솔에서 일반 사용자 2명 이상 생성(`admin create-user`) 또는 아래 관리자 화면에서 생성
- [ ] 서버를 loopback으로 실행(`http://127.0.0.1:<port>/`). LAN·TLS 점검은 `-tls -allow-lan` 실행 후 `https://localhost:<port>/`에서 별도로
- [ ] 점검 브라우저: macOS Safari, Chrome(가능하면 Firefox). 개발자 도구 콘솔을 열어 둘 것

## 공통

- [ ] 처음 접속 시 로그인 화면만 보이고 데이터가 보이지 않는다
- [ ] 틀린 비밀번호 → "아이디 또는 비밀번호가 올바르지 않습니다", 반복 실패 → 시도 제한 안내
- [ ] 로그인 후 개발자 도구 콘솔에 CSP·Trusted Types 위반 오류가 **없다**
- [ ] 쿠키: `withalbum_access`·`withalbum_refresh`는 HttpOnly, 세 쿠키 모두 SameSite=Strict (TLS에서는 Secure)
- [ ] 15분 이상 지난 뒤 동작해도 자동 갱신되어 계속 사용된다(또는 다시 로그인 화면으로 간다)
- [ ] 로그아웃 → 로그인 화면, 새로고침해도 로그인 화면
- [ ] 이름에 `<b>x</b>`, `<img src=x onerror=alert(1)>` 같은 문자열을 넣은 앨범·사용자 표시 이름이 **글자 그대로** 보이고 실행되지 않는다
- [ ] 다크 모드에서 글자가 읽힌다, 좁은 창(휴대폰 폭)에서 표가 가로 스크롤로 보인다

## 일반 사용자 시나리오

- [ ] 메뉴에 "사용자 관리"·"서버·저장소"가 보이지 않는다
- [ ] 앨범 생성 권한이 없으면 "앨범 만들기" 입력이 보이지 않는다
- [ ] 받은 초대가 개요에 보이고 "수락" 후 내 앨범에 해당 역할로 나타난다
- [ ] OWNER가 아닌 앨범을 펼치면 관리 메뉴 없이 안내만 보인다
- [ ] 업로드 테스트: 참여자·소유자는 "업로드 완료", 업로드 전용은 "전송했습니다", 보기 전용 앨범은 선택 목록에 없다
- [ ] 비밀번호 변경 → 다른 기기(앱·다른 브라우저)는 로그아웃, 이 브라우저는 유지
- [ ] 내 기기 목록에서 다른 기기 해지 → 해당 기기가 다음 요청에서 로그아웃. 현재 브라우저 해지 → 로그인 화면

## 앨범 소유자(OWNER) 시나리오

- [ ] 앨범 펼치기 → 멤버 표(이름·사용자 ID·역할)와 대기 중인 초대 목록이 보인다
- [ ] 사용자 ID로 초대 보내기 → 대상 계정에서 수락 가능. 없는/비활성 ID는 오류 메시지
- [ ] 초대 취소 → 대상 계정의 초대 목록에서 사라진다
- [ ] 역할 변경(보기 전용 ↔ 참여자 ↔ 업로드 전용) → 대상 계정의 다음 동작에 반영
- [ ] 내보내기 → 확인 창 → 대상 계정의 앨범 목록에서 사라진다
- [ ] 소유권 이전 → 확인 창 → 나는 참여자가 되고 관리 메뉴가 사라진다
- [ ] 앨범 보관 → 이름을 정확히 입력해야만 진행, 보관 후 모든 계정의 목록에서 사라진다

## 서버 관리자(SERVER_ADMIN) 시나리오

- [ ] 사용자 관리: 새 사용자 만들기(일반/관리자, 앨범 생성 허용) → 목록에 나타나고 그 계정으로 로그인 가능
- [ ] "관리" → 역할·앨범 생성 권한 저장 → 대상 계정의 다음 요청에 반영(예: 앨범 만들기 표시)
- [ ] 마지막 관리자를 강등·비활성화하려 하면 거부 메시지
- [ ] 관리 패널의 "소유 앨범"에 개수만 보이고 **앨범 이름·사진은 보이지 않는다**
- [ ] 다른 사람의 앨범은 관리자의 "내 앨범"에 나타나지 않는다(초대받지 않은 한)
- [ ] 사용 중 앨범을 가진 사용자 비활성화 → "소유한 앨범이 있어 비활성화할 수 없습니다" + 오너가 직접 이전·보관하라는 안내
- [ ] 그 사용자가 앨범을 모두 보관한 뒤: 넘겨받을 계정 선택 → "보관 앨범 N개 재배정 후 비활성화" → 계정이 비활성으로 바뀌고 그 계정의 모든 기기가 로그아웃
- [ ] 넘겨받은 계정에서도 보관 앨범이 보이지 않는다
- [ ] 다시 활성화 → 로그인 가능
- [ ] 다른 사용자의 기기 목록·해지 → 해당 기기가 로그아웃
- [ ] 서버·저장소: 저장소 연결됨, 여유 공간, 업로드 예약, 무결성, 시작 시 점검 개수가 보이고 경로·볼륨 ID는 보이지 않는다
- [ ] TLS 꺼짐 안내(평문 실행) / `-tls` 실행 시 지문이 콘솔 `withalbum-server tls` 출력과 같다
- [ ] (선택) 외장 디스크를 뺀 상태에서 새로고침 → 저장소 "사용 불가"

## 정리
