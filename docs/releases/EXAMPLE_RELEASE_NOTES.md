# v0.1.0-alpha.1 — 개발용 배포 예시 (게시된 릴리스 아님)

> 아래 내용은 릴리스 노트 형식의 예시입니다. GitHub에 아직 공개된 버전이 아닙니다.

## 새 기능
- 로컬 웹 대시보드에서 서버 상태와 공유 폴더 확인
- 테스트 파일 업로드 및 SHA-256 중복 처리
- macOS / Linux / Raspberry Pi 실험용 빌드 골격

## 해결한 문제
- 프로토타입에서 외부 인터페이스로 직접 바인딩하지 못하도록 제한

## 알려진 제약
- 인증/폴더 권한, SQLite, 대용량 업로드 재개 미구현
- 실제 사용용이 아닌 localhost-only 실험판
- macOS GUI 설치 프로그램과 코드 서명/공증 미구현

## 업데이트 주의
- 프로토타입 단계로 마이그레이션 호환성은 보장하지 않습니다.
