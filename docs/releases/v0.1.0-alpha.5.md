# WithAlbum Server v0.1.0-alpha.5 (prerelease)

**정식판이 아닙니다.** 주의 사항은 [v0.1.0-alpha.2 릴리스 노트](v0.1.0-alpha.2.md)와 [v0.1.0-alpha.1 릴리스 노트](v0.1.0-alpha.1.md)를 따르고, Docker 구성은 [v0.1.0-alpha.3 릴리스 노트](v0.1.0-alpha.3.md)를 따릅니다.

## 새 기능: Google·Apple로 가입

지금까지 Google·Apple 로그인은 관리자가 만든 계정에 **먼저 연결해 둔** 사람만 쓸 수 있었습니다. 이번 판부터 Google·Apple 계정으로 **가입**할 수 있습니다.

| 경우 | 결과 |
|---|---|
| 가족이 보낸 **앨범 초대 링크**를 열고 "Google 계정으로 가입하고 참여" | 계정이 바로 생기고 그 앨범에 들어갑니다. |
| 링크 없이 로그인 화면에서 "Google 계정으로 로그인" → "가입 요청" | 계정이 **승인 대기**로 생깁니다. 관리자가 대시보드 **사용자 → 가입 요청**에서 승인하면 로그인할 수 있고, 거절하면 지워집니다. |
| 이미 계정이 있는 Google·Apple 계정 | 그냥 로그인합니다. |

- **누구나 바로 가입하는 공개 가입은 없습니다.** 서버가 인터넷(Funnel)에 열려 있어도, 주소를 아는 낯선 사람은 링크나 관리자 승인 없이는 쓸 수 있는 계정을 얻지 못합니다.
- 승인을 기다리는 요청은 최대 20개입니다. 링크 없는 가입 요청을 아예 받지 않으려면 `.env`에 `WITHALBUM_SIGN_UP_REQUESTS=off`를 넣습니다(초대 링크 가입은 그대로).
- 가입으로 만든 계정은 비밀번호가 없는 것과 같아서(아무도 모르는 무작위 값) Google·Apple로만 로그인합니다. 앨범 만들기 권한은 기본적으로 꺼져 있습니다.
- 서버 시작 로그는 `sign-in with Google/Apple: google, apple (sign-up with an invite link or the administrator's approval)`로 바뀌었습니다.
- 데이터베이스 마이그레이션 0020(`sign_up_requests`)이 시작할 때 자동으로 적용됩니다. 업데이트 전에 평소처럼 백업을 권합니다.

앱은 0.1.0+5 이상이 필요합니다(이전 앱은 가입 버튼이 없습니다).

## 업데이트 (Docker)

사진 보관 폴더, TLS 키, 연결 정보, `.env`는 그대로 둡니다.

```sh
git fetch && git checkout v0.1.0-alpha.5
docker compose build
docker compose up -d
docker compose logs -f withalbum   # 가입·로그인 시도가 기록됩니다
```
