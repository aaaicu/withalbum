# WithAlbum Server v0.1.0-alpha.4 (prerelease)

v0.1.0-alpha.3의 **수정판**입니다. **정식판이 아닙니다.** 주의 사항은 [v0.1.0-alpha.2 릴리스 노트](v0.1.0-alpha.2.md)와 [v0.1.0-alpha.1 릴리스 노트](v0.1.0-alpha.1.md)를 그대로 따르고, Docker 구성 변경은 [v0.1.0-alpha.3 릴리스 노트](v0.1.0-alpha.3.md)를 따릅니다.

## 고친 것: Google 로그인 실패가 로그에 남지 않음

alpha.3에서 Android 앱이 Google 계정을 고른 뒤 아무 반응이 없고, 서버에도 로그인·연결 기록이 없는 경우가 있었습니다. 서버는 **성공한** 로그인·연결만 감사 기록에 남기고 거절은 남기지 않아서, "앱이 서버에 오지 않았다"와 "서버가 거절했다"를 가를 수 없었습니다.

이번 판은 아래를 서버 로그(`docker compose logs withalbum`)에 남깁니다. 토큰 자체는 남기지 않습니다.

| 로그 | 뜻 |
|---|---|
| `sign-in: nonce issued (providers [google apple])` | 앱이 로그인을 시작했습니다(서버까지 왔음). |
| `sign-in: /api/v1/auth/sign-in "google" rejected: invalid_identity_token (invalid identity token: audience "…")` | 토큰이 다른 클라이언트 ID용입니다. 적힌 ID를 `WITHALBUM_GOOGLE_CLIENT_IDS`에 넣을지 확인합니다. |
| `… rejected: invalid_identity_token (… expired_or_clock_skew)` | 서버 시계가 틀렸거나 토큰이 만료됐습니다. |
| `… rejected: invalid_identity_token (nonce unknown, used or expired)` | nonce를 받은 뒤 10분이 지났거나 서버가 다시 시작됐습니다. |
| `… rejected: provider_unavailable (…)` | `keys` 컨테이너가 키를 아직 못 받았습니다(`docker compose logs keys`). |
| `sign-in: google account is not linked to any user (no account is created)` | 아직 연결하지 않은 Google 계정입니다. 설정 → 로그인 방법에서 먼저 연결합니다. |
| `sign-in: link "google" rejected: current password does not match` | 연결할 때 입력한 비밀번호가 틀렸습니다. |

`nonce issued`가 있는데 그 뒤 아무 줄도 없으면, 앱이 Google에서 토큰을 받지 못한 것입니다. 앱 0.1.0+4는 이 경우 무반응 대신 "Google이 이 앱을 확인하지 못했어요"를 보입니다. 대개 Google Cloud의 **Android** OAuth 클라이언트에 등록한 패키지 이름·서명 SHA-1이 설치한 앱과 다른 경우입니다.

## 업데이트 (Docker)

사진 보관 폴더, TLS 키, 연결 정보, `.env`는 그대로 둡니다.

```sh
git fetch && git checkout v0.1.0-alpha.4
docker compose build
docker compose up -d
docker compose logs -f withalbum   # 앱에서 Google 로그인을 시도하며 확인
```
