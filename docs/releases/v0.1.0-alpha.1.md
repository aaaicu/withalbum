# WithAlbum Server v0.1.0-alpha.1 (prerelease)

> **초안 — 아직 발행되지 않았습니다.** 발행 전에 아래 "실기기 검증" 표를 `docs/MACMINI_E2E_CHECKLIST.md` 11장의 실제 결과로 채우고 이 인용문을 지웁니다.

위드앨범 서버의 첫 실험판입니다. Mac mini + 외장 디스크에서 가족 사진 원본을 보관하는 셀프호스팅 서버를 시험해 보기 위한 개발자용 빌드이며, **정식판이 아닙니다.**

## 꼭 읽어 주세요

- **인터넷에 공개하지 마세요**(포트포워딩·공개 리버스 프록시 금지). LAN은 `-tls -allow-lan`으로만, 같은 집 네트워크에서만.
- **대체할 수 없는 원본 사진의 유일한 보관소로 쓰지 마세요.** 백업(`backup -to`)을 별도 디스크에 두세요.
- macOS 바이너리는 **Apple 서명·공증이 되지 않은 ZIP**입니다(DMG/PKG 아님). Gatekeeper 경고가 나올 수 있습니다.
- 모바일 앱은 아직 배포되지 않았습니다. 이 릴리스는 서버와 내장 웹 관리 화면만 포함합니다.
- 데이터 형식·API(`docs/API_v2.yaml` 2.0.0-draft)는 alpha 동안 바뀔 수 있습니다.

## 들어 있는 것

- 저장: SQLite 메타데이터, SHA-256 원본 보관(성공 응답 전 파일·DB 디스크 기록, 기동 재조정), 여유 공간 예약, 외장 디스크가 빠지면 쓰기 거부(fail closed)
- 계정: 설치 화면(이 Mac에서만, 1회용 코드) 또는 콘솔 `admin init`, Argon2id, 기기 세션(access 15분, refresh 30일 회전, 최대 90일 — 응답의 `session_expires_at`)
- 앨범: 소유자·초대·역할(참여/보기/업로드 전용)·소유권 이전·보관, 요청마다 권한 재확인
- 동기화: 폴더별 변경 피드(cursor, `asset_added`/`asset_removed`/`asset_updated`), 멱등 업로드(`Idempotency-Key`), 512MiB 초과는 재개 업로드
- 미리보기: JPEG/PNG/GIF 내장, HEIC·영상은 macOS `sips`·`ffmpeg`가 있을 때
- 운영: `verify [-hash]`, `backup -to`, `restore -from`, TLS 지문(`withalbum-server tls`), 개발용 LaunchAgent/systemd 스크립트

## 알려진 제약

README의 "Known limitations"를 참고하세요. 주요 항목: 서명·공증 없음, 로그인 세션에서만 도는 LaunchAgent, 디스크 재연결 후 서버 재시작이 필요할 수 있음, 디스크 UUID 대조 없음, 원격/예약 백업 없음, 앱 TLS 핀닝 실기기 미검증.
