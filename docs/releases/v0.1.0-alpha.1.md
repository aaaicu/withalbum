# WithAlbum Server v0.1.0-alpha.1 (prerelease)

위드앨범 서버의 첫 실험판입니다. Mac mini + 외장 디스크에서 가족 사진 원본을 보관하는 셀프호스팅 서버를 시험해 보기 위한 빌드이며, **정식판이 아닙니다.**

이 저장소의 `main`은 이번 릴리스부터 실제 개발 중인 서버와 같아집니다. 이전 `main`(2026-10-17 첫 공개)은 인증·권한이 없는 시제품이었습니다.

## 꼭 읽어 주세요

- **포트포워딩·공개 리버스 프록시로 인터넷에 열지 마세요.** 집 밖 접속은 이 서버가 지원하는 두 경로(Tailscale Funnel TCP 전달, 종단 간 암호화 중계)만 쓰세요. 두 경로 모두 앱 기능만 열리고 관리 화면·설치 화면은 막힙니다.
- 집 밖 접속을 켜기 전에 [`docs/HOME_NETWORK_ISOLATION.md`](../HOME_NETWORK_ISOLATION.md)를 읽어 주세요. 서버를 돌리는 컴퓨터와 같은 망에 홈캠·NAS 같은 다른 기기가 있으면 그 기기들을 먼저 점검해야 합니다.
- **대체할 수 없는 원본 사진의 유일한 보관소로 쓰지 마세요.** 백업(`backup -to`)을 별도 디스크에 두세요.
- macOS 바이너리는 **Apple 서명·공증이 되지 않은 ZIP**입니다(DMG/PKG 아님). Gatekeeper 경고가 나올 수 있습니다.
- 모바일 앱은 아직 스토어에 배포되지 않았습니다(TestFlight·Play 내부 테스트 준비 중). 이 릴리스는 서버와 내장 웹 관리 화면만 포함합니다.
- 데이터 형식·API(`docs/API_v2.yaml` 2.0.0-draft)는 alpha 동안 바뀔 수 있습니다.

## 들어 있는 것

- 저장: SQLite 메타데이터, SHA-256 원본 보관(성공 응답 전 파일·DB 디스크 기록, 기동 재조정), 여유 공간 예약, 외장 디스크가 빠지면 쓰기 거부(fail closed)
- 계정: 설치 화면(이 Mac에서만, 1회용 코드) 또는 콘솔 `admin init`, Argon2id, 기기 세션(access 15분, refresh 30일 회전, 최대 90일), 기기별 로그아웃·내 다른 기기 로그아웃
- 앨범: 오너·초대·역할(참여/보기/업로드 전용)·소유권 이전·보관·삭제(30일 휴지통), 비공개 사진, 요청마다 권한 재확인. 서버 관리자도 초대받지 않은 앨범은 볼 수 없음
- 반응: 좋아요·댓글·멘션, 내 활동
- 동기화: 폴더별 변경 피드(cursor, tombstone), 멱등 업로드(`Idempotency-Key`), 512MiB 초과는 재개 업로드
- 미리보기·재생: JPEG/PNG/GIF 내장, HEIC·영상은 macOS `sips`·`ffmpeg`가 있을 때, 동영상 재생용 720p 경량본
- 사진 정보: 촬영 시각·위치·카메라·픽셀 크기
- 연결: TLS 1.3 + 앱의 공개키 지문 고정, LAN은 `-tls -allow-lan`으로만, 집 밖은 Tailscale Funnel(TCP 전달, 루프백 리스너) 또는 종단 간 암호화 중계(`withalbum-relay`는 소스만 — 이 릴리스의 압축 파일에는 없음)
- 보안: 위협 모델·자체 리뷰(`docs/THREAT_MODEL.md`, `docs/SECURITY_REVIEW_2026-10.md`), 라우트×호출자×경로 권한 전수 시험, 원격·집 로그인 실패 한도 분리, root 기동 거부, 감사 로그
- 운영: `verify [-hash]`, `backup -to`, `restore -from`, TLS 지문(`withalbum-server tls`), 내장 관리 화면, 메뉴 막대 앱(직접 빌드, 서명 없는 DMG), 개발용 LaunchAgent/systemd 스크립트

전체 변경은 [`CHANGELOG.md`](../../CHANGELOG.md).

## 알려진 제약

README의 "Known limitations"를 참고하세요. 주요 항목: 서명·공증 없음, 로그인 세션에서만 도는 LaunchAgent, 디스크 재연결 후 서버 재시작이 필요할 수 있음, 원격·예약 백업 없음, 실기기 점검 미완료, 외부 보안 리뷰 전.
