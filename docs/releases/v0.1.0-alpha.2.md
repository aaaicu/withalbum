# WithAlbum Server v0.1.0-alpha.2 (prerelease)

위드앨범 서버의 두 번째 실험판입니다. **정식판이 아닙니다.** 이전 판의 주의 사항은 [v0.1.0-alpha.1 릴리스 노트](v0.1.0-alpha.1.md)를 그대로 따릅니다.

## 꼭 읽어 주세요

- **포트포워딩·공개 리버스 프록시로 인터넷에 열지 마세요.** 집 밖 접속은 Tailscale Funnel TCP 전달과 종단 간 암호화 중계만 쓰세요.
- 공유기에서 망을 나눌 수 없으면 이번 판의 **Docker 구성**([`docs/DOCKER.md`](../DOCKER.md))으로 서버가 집 안 다른 기기·인터넷에 닿지 못하게 할 수 있습니다. 이 구성은 **실제 Docker에서 아직 검증하지 않은 시험판**입니다.
- **대체할 수 없는 원본 사진의 유일한 보관소로 쓰지 마세요.** 백업(`backup -to`)을 별도 디스크에 두세요.
- 데이터 형식·API(`docs/API_v2.yaml` 2.0.0-draft)는 alpha 동안 바뀔 수 있습니다. DB 마이그레이션 **0018**(`user_identities`)이 기동 시 자동 적용됩니다. 되돌리려면 업그레이드 전 백업(`backup -to`)을 두세요.

## 바뀐 것

- **Docker 격리(M58):** 서버 컨테이너는 바깥으로 나가는 길이 없는 `internal` 네트워크에만 두고, 휴대폰·Funnel 연결은 같은 이미지의 전달 컨테이너(`withalbum-server forward`)가 받습니다. uid 10001, 읽기 전용 FS, capability 전부 제거. `withalbum-server reach`로 격리 확인, `WITHALBUM_LAN_URL`로 연결 QR 주소 지정, Linux에서 libheif `heif-dec`로 HEIC 미리보기.
- **Google·Apple 로그인(M54):** 계정에 Google·Apple 계정을 하나씩 연결해 비밀번호 대신 로그인. 서버가 ID 토큰을 직접 검증(공개키만 받음), 연결에는 현재 비밀번호 필요, 로그인으로 새 계정을 만들지 않음. 기본은 Google 꺼짐(`-google-client-ids`). 설명 [`docs/SIGN_IN.md`](../SIGN_IN.md).
- **빠른 동기화(M53):** `GET /api/v1/sync/state` — 모든 앨범의 변화 여부를 한 번에(ETag·롱폴·앨범별 내용 해시).
- 새 사진 알림 설계 문서(M39, 깨우기 신호 게이트웨이는 보류).

전체 변경은 [`CHANGELOG.md`](../../CHANGELOG.md).
